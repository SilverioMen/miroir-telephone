En attente du téléphone

  1. Sur ce Mac, active « Récepteur AirPlay » dans les réglages.
  2. Sur l'iPhone, connecté au même Wi-Fi, ouvre le Centre de contrôle puis touche « Recopie de l'écran ».
  3. Choisis ce Mac dans la liste. Saisis le code affiché si l'iPhone le demande.
Une appli qui masque son contenu (banque) apparaît en noir : c'est normal.
