# Installer Miroir Téléphone sur Android

Android 10 ou plus récent est nécessaire.

1. Copiez le fichier `.apk` sur le téléphone (cable, messagerie ou lien de telechargement), puis ouvrez-le depuis l'application « Fichiers ».
2. Si Android bloque l'installation, appuyez sur « Paramètres » et activez « Autoriser depuis cette source » pour l'application que vous utilisez (Fichiers, Chrome...). Revenez en arrière et appuyez sur « Installer ».
3. Ouvrez « Miroir Téléphone ». Autorisez l'appareil photo : il sert uniquement à lire le QR code affiche sur le Mac.
4. Visez le QR code du Mac. Appuyez sur « Démarrer » quand Android demande de confirmer la capture de l'écran. Votre écran apparaît alors sur le Mac.
5. Pour arrêter, appuyez sur « Arrêter » dans l'application ou dans la notification.

## Si le partage s'interrompt

Certains téléphones coupent les applications en arrière-plan pour économiser la batterie. Dans « Paramètres », « Applications », « Miroir Téléphone », « Batterie », choisissez « Sans restriction ».

Le téléphone et le Mac doivent rester sur le meme Wi-Fi.
