# Installer Miroir Téléphone sur Mac

L'application n'est pas signée par Apple. Le Mac demande donc une confirmation la premiere fois. C'est normal et ne se fait qu'une seule fois.

1. Ouvrez le fichier `.dmg` qui correspond à votre Mac : `arm64` pour un Mac récent (puce M1, M2, M3 ou M4), l'autre fichier pour un Mac plus ancien (processeur Intel). En cas de doute, cliquez sur le menu Pomme, puis « À propos de ce Mac » : la ligne « Puce » ou « Processeur » indique la bonne version.
2. Dans la fenetre qui s'ouvre, glissez « Miroir Téléphone » dans le dossier « Applications ».
3. Ouvrez le dossier « Applications » et double-cliquez sur « Miroir Téléphone ». Un message indique que l'app ne peut pas etre ouverte. Cliquez sur « OK ».
4. Ouvrez « Réglages Système », puis « Confidentialité et sécurité ».
5. Descendez jusqu'au message « Miroir Téléphone a été bloqué ». Cliquez sur « Ouvrir quand même » et saisissez le mot de passe de votre Mac.
6. L'application s'ouvre et affiche un QR code. Elle s'ouvrira ensuite normalement.

Si le Mac demande l'autorisation de recevoir des connexions sur le réseau, acceptez : sans cela le téléphone ne peut pas se connecter.

Le Mac et le téléphone doivent etre sur le meme Wi-Fi.
